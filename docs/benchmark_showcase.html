topK Tradeoff

候选池不是越大越好

正式协议只保留 `32 / 64 / 128`。从平均 `RAG answer_relevancy` 和时延一起看， `32` 是最适合拿去讲的整体折中点。

Stability Duel

正式稳定性页面不再承担“所有早期 repeated-sampling 计划”的包袱，而是只讲 clean selected-RAG release。 这让最终叙事非常直接：`MiniMax-M2.7` 质量领先，`DeepSeek-V3.2` 延迟更低。
