# Benchmark Algorithm Resume Pack

This directory collects the most algorithm-facing materials for `llm-eval-benchmark`.

## Files

- `benchmark_experiment_matrix.csv`
  - machine-readable summary of the official benchmark components
- `benchmark_experiment_matrix.md`
  - one-page human-readable comparison sheet
- `benchmark_protocol_summary.md`
  - what was frozen, what was compared, and why the protocol is meaningful
- `benchmark_failure_analysis.md`
  - what kinds of benchmark weaknesses or tradeoffs were exposed
- `benchmark_reliability_note.md`
  - why the benchmark is credible and what its official boundary is

## Suggested use

- Resume / project summary:
  - use `benchmark_experiment_matrix.md`
- Interview explanation:
  - use `benchmark_protocol_summary.md`
  - use `benchmark_failure_analysis.md`
  - use `benchmark_reliability_note.md`
